# Code of conduct

Treat contributors and users with respect. Make technical disagreements about
ideas and behavior, rather than people. Welcome different experience levels and
backgrounds; give clear, constructive feedback.

Harassment, discriminatory remarks, threats, unwanted sexual attention, and
sharing another person's private information are unacceptable in issues, pull
requests, discussions, and other project spaces.

Maintainers may edit or remove inappropriate content, close discussions, or
restrict participation when necessary. Responses should be proportionate and
consistent. Reports should be handled discreetly.

To report a conduct concern, contact a maintainer privately using a contact
channel listed on their GitHub profile. If none is available, open an issue
requesting a private contact channel without including personal or sensitive
details. Maintainers who are involved in a report should not handle that report.
